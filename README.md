# Чесно

Локальный трекер расходов и доходов с минималистичным тёмным интерфейсом для iPhone. Работает как устанавливаемая PWA: финансовые данные сохраняются на устройстве, сервер раздаёт только файлы приложения.

<img src="design/preview.png" alt="Чесно: общий остаток, все счета и история операций" width="360">

## Возможности

- Все счета и общий остаток на главной; месячные доходы и расходы, фильтрация по счёту.
- Быстрый ввод, редактирование и удаление операций: сумма, дата, счёт, обязательные категория и подкатегория, заметка.
- Свои счета с начальным остатком, категории и подкатегории.
- Переводы между счетами, которые не увеличивают доходы и расходы.
- История и статистика по месяцам, категориям и подкатегориям.
- Резервные копии JSON с восстановлением и экспорт операций в CSV.
- Работа офлайн после первого успешного открытия с интернетом.

При первом запуске создаётся счёт «Основной» с нулевым остатком и готовые категории. Демонстрационных операций нет. Валюта — рубли.

## На iPhone

Откройте опубликованный HTTPS-сайт в Safari, дождитесь загрузки, затем выберите **«Поделиться» → «На экран „Домой“»**. Приложение появится с отдельной иконкой. Сохранённые операции доступны после закрытия и повторного открытия приложения, в том числе без интернета.

Настройки открываются кнопкой с шестерёнкой. Там доступны счета, категории, импорт, экспорт и инструкция установки.

## Данные и резервные копии

Данные хранятся локально в IndexedDB и привязаны к устройству и адресу сайта. Автоматической синхронизации между телефонами и разными доменами нет. Очистка данных сайта или сброс телефона может удалить записи, поэтому периодически сохраняйте JSON-копию через настройки.

Импорт JSON-файла до **50 МиБ** показывает содержимое перед подтверждением и заменяет текущие данные целиком. CSV предназначен для Excel и Numbers; для полного восстановления используйте JSON.

## Локальный запуск

Нужен **Node.js 20+**. Устанавливать зависимости не требуется.

```sh
npm run dev
```

Откройте адрес, напечатанный сервером. Для модулей приложения и офлайн-режима нужен HTTP-сервер; открытие `index.html` как `file://` не поддерживается. В опубликованной версии требуется HTTPS.

## Развёртывание на Vercel

Импортируйте репозиторий с **Root Directory: `./`** и **Framework Preset: Other**. Файл `vercel.json` запускает `npm run build` и публикует статическую папку `design`. Сборка без зависимостей автоматически вычисляет версию офлайн-кэша по содержимому файлов. При Git-интеграции коммиты в `main` запускают новый деплой.

## Проверки

```sh
npm test
npm run check
```

Тесты проверяют расчёты в целых копейках, операции и переводы, связи счетов и категорий, даты, резервные копии и версию офлайн-кэша. Если после изменения файлов `npm run check` сообщает об устаревшем кэше, выполните `npm run build`.

Браузерные сценарии выполняются в Chromium; проверка на физическом iPhone и в Safari не проводилась.
