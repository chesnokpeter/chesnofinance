# Проверки

`npm test` запускает доменные тесты через встроенный Node.js test runner. Приложению не нужны сторонние пакеты.

Браузерный сценарий проверяет настоящий интерфейс, IndexedDB, файлы резервных копий и офлайн-запуск. Он использует отдельный временный профиль Chromium и тестовые данные; пользовательские браузерные профили не затрагиваются.

Для браузерных проверок нужен Python с пакетом Playwright и установленный Chromium. Это инструменты разработки, они не входят в зависимости приложения:

```sh
python3 -m pip install playwright
npm run dev
```

В другом терминале:

```sh
python3 tests/browser_smoke.py
```

При необходимости укажите путь к Chromium через `--chromium /path/to/chromium` или переменную `CHESNO_CHROMIUM`, адрес сервера — через `--base-url`. По умолчанию сценарий открывает локальный сервер на порту `4173`.

Проверяются:

- Первый запуск с пустыми операциями, создание и изменение счетов.
- Расход, доход, перевод, редактирование и удаление; обязательная подкатегория.
- Категории и подкатегории, безопасное отображение заметок, статистика.
- Экспорт JSON/CSV, подтверждение импорта, восстановление и отклонение повреждённых файлов.
- Сохранение после перезагрузки страницы и перезапуска браузера.
- Офлайн-перезагрузка, добавление операции без сети и повторная перезагрузка.
- Даты и месяцы, мобильная геометрия на ширинах 320, 375, 390 и 430 px.
- Одновременное редактирование из двух вкладок, отказ сохранения из-за квоты и недоступность IndexedDB.

Для отдельных проверок ошибок хранилища и конфликтов вкладок можно добавить `--failure-cases-only`.

Это проверка Chromium. Физический iPhone и Safari следует проверять отдельно.
